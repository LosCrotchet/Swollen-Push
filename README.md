# Swollen Push（胀缩）

> **早期测试中** · 当前版本 `0.3.6`

一个为 Game Jam 准备的推箱子游戏。游戏目标是**将火球推入火盆**，并利用方块的膨胀与收缩机制推动火球。

---

## 游戏操作

| 按键           | 作用               |
| -------------- | ------------------ |
| 鼠标左键       | 膨胀方块           |
| 鼠标右键       | 收缩方块           |
| R              | 重新开始当前关卡   |

## 编辑模式

在游戏界面按下 `P` 键，可打开调试面板并进入编辑模式。

**编辑操作**

| 操作           | 作用               |
| -------------- | ------------------ |
| 鼠标左键       | 放置当前选中的物体 |
| 鼠标右键       | 清除物体           |

**可放置物体**

- 方块（普通 / 黏性 / 固定 / 爆炸）
- 火球
- 火盆
- 墙壁（在游戏界面中显示为地图边界）

**地图保存与读取**

- **保存**：将当前地图编码为 Base64 字符串
- **读取**：将地图字符串粘贴到文本框后读取

---

## 游戏规则

- 游戏包含三种核心物体：**方块**、**火球**、**火盆**
- 目标：把火球推到火盆所在格，二者相遇即通关
- 方块有 **1×1**、**3×3**、**5×5** 三种尺寸，可通过鼠标左/右键改变大小
- 方块不能超出地图边界
- 火球和火盆均可被推动或被其他物体黏连

### 方块类型

| 类型     | 特性                                                                 |
| -------- | -------------------------------------------------------------------- |
| 普通方块 | 可被其他方块推动或黏住                                               |
| 黏性方块 | 可黏住与其接触的物体（固定方块除外）                                 |
| 固定方块 | 无法被推动或黏住                                                     |
| 爆炸方块 | 额外膨胀一次后爆炸消失；爆炸无视边界和固定方块，但无法推动固定方块 |

> 0.3.3 更新：现在你会在某些关卡中遇到一种奇特的鸟类，它可以变化为方块并被放置在地图上。

## 关卡格式（JSON）

```json
"TEST-1": {
    "data": "MDAwMDAwMDAwMDAwMDc3NzAwMDAwMDAwMDAwMDA3NzcwMDAwMDAwMDAwMDAwNzc3MDAwMTAwNTAwNjAwMDc3NzAwMDAwMDAwMDAwMDA3NzcwMDAwMDAwMDAwMDAwNzc3MDAwMDAwMDAwMDAwMDc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3Nzc3",
    "hint": "[测试关卡]本关卡可以自由放置一些方块......",
    "quota": {
        "normal": 1,
        "sticky": 1,
        "fixed": 1,
        "boom": 1
    }
}
```
- `TEST-1`: 关卡的标题
- `data`：Base64 编码的地图数据
- `hint`：关卡提示文本
- `quota`：各类型方块的可使用数量
