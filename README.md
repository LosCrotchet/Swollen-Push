# Swollen Push
（中文名：胀缩）

这是一个为Gamejam而写的类推箱子游戏。

当前版本：0.2.2

### 操作说明
鼠标左键：膨胀方块

鼠标右键：收缩方块

[编辑模式]

鼠标左键：放置内容

鼠标右键：清除内容

目前可以设置的物体有：方块（普通、黏性、固定、横向、竖向）、箱子、墙壁、洞穴；




保存：将当前地图以json文件保存至当前目录下

读取：读取当前目录下的level.json文件

## 规则
游戏里有四种物体：**箱子、方块、墙壁和洞穴**；

游戏的目标是**把箱子推进洞穴**；

**方块可以改变大小**：鼠标左键方块使其膨胀，右键使其收缩——可以利用这一点推动箱子；

方块的大小有1x1、3x3、5x5三种形态（横向和竖向方块例外）；

墙壁无法被推动，也改变不了大小；

洞穴没有体积，只需要将箱子推到这里就好；

方块有**五种**类型：**普通方块、黏性方块、固定方块、横向方块、竖向方块**；

普通方块可以被其它方块推动或黏住；

黏性方块可以黏住其接触到的物体，除了固定方块和墙壁；

固定方块无法被其它方块推动和黏住；

横向方块只能在水平方向上膨胀和收缩，竖向方块同理；
